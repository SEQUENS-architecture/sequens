# SEQUENS VALUES SPEC (v1) - held until generation is live

School vision, mission and values are configurable input, editable in Settings per
school, exactly like the grading scale. Never hard-coded. Read from CONFIG at generation.

El Alsson values (default): Respect, Responsibility, Integrity, Resilience, Empathy.

## The one rule that keeps this honest

Values are woven where the lesson genuinely affords it, named where they are real, and
left out where they would be a stretch. No value is stamped on a lesson that does not
carry it.

- The generator inspects the specific objective and content for a genuine hook, the point
  where a value actually lives (a Wonder writing lesson on standing up for others carries
  Empathy or Integrity because the text is about exactly that).
- Where a hook exists, the value is named at that point in the lesson, not in a banner.
- Where none exists (most of a place-value maths lesson), no value is forced. A lesson may
  carry no value, and that is correct, not a gap.
- The validator rejects a lesson that asserts a value the content does not support, the
  same way it rejects a vague statement. Tokenism fails.

## Reach

`CONFIG.valuesReach` decides where values may surface: `lessons` only, or
`lessons+reports`. When reports are included, a value may appear in a comment only where
the pupil's actual work or conduct evidences it, held to the same honesty bar.
